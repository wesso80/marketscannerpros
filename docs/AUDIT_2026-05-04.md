## CRITICAL — fix this week

1. **Backtest lookahead bias.** `lib/backtest/strategyExecutors.ts` (L104–L111) and `lib/backtest/runStrategy.ts` (L100–L250) fill entries at `close[i]` on the same bar the signal fires. Every backtest result is overstated. Fix by signaling on bar `i` and filling on `open[i+1]`, or using `close[i-1]`.
2. **Confidence formula inverts direction.** `app/api/scanner/candidates/route.ts` (L133–L135) — score of 0 (max bearish) returns confidence 100. Use signed direction + magnitude.
3. **Edge middleware HMAC compare is not timing-safe.** `middleware.ts` (L34–L45) uses `if (sig !== expected)`. Replace with `crypto.subtle`-based constant-time compare (Edge-compatible) and unify with `lib/auth.ts` (L14–L27).
4. **Cross-tenant admin leak.** `app/api/admin/delete-requests/route.ts` (L9–L28) has `SELECT * FROM delete_requests` with no `workspace_id` filter. Either scope to admin's workspace or document explicitly as global-admin-only with a tenant-audit comment.
5. **Stripe webhook fallback path skips signature check.** `app/api/subscription/update/route.ts` (L14–L43) — `if (webhookSecret && stripeSignature)` silently accepts when signature is absent. Always require signature; 400 if missing.
6. **CSP is permissive.** `next.config.mjs` (L20–L60) allows `unsafe-inline` and `unsafe-eval` on `script-src`, `http:` on `img-src`, and **no HSTS**. Move to nonce-based CSP, drop `unsafe-eval`, add `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`.
7. **Public scanner has no freshness/source envelope.** `app/api/scanner/run/route.ts` (L310–L380) returns indicator-derived results without source/age. Wrap with `wrapTruth()` or equivalent so UI can render stale badges.

## HIGH — within sprint

8. **Admin route freshness.** Audit script flagged ~24 admin routes missing `wrapTruth()`: `priority-desk` is now wrapped; still pending include `signals`, `signals/scorecard`, `signals/stats`, `stats`, `usage-analytics`, `symbol/[symbol]`, `scanner/live`, `research-packet`, `research-scheduler`. Run `npm run audit:admin:freshness` for the live list.
9. **Admin operator fallback overpermissive.** `app/api/admin/cg-usage/route.ts` (L13–L19) accepts `isOperator()` fallback on a regular user session. Make admin-only.
10. **Dev bypass envs still wired.** `DEV_AUTH_BYPASS` and `FREE_FOR_ALL_MODE` (`lib/auth.ts` L46, `middleware.ts` L222–L231) can fully unlock the platform from a single env var. Gate behind `NODE_ENV !== 'production'` AND a second confirmation env.
11. **Hardcoded admin emails.** `lib/entitlements.ts` (L14) — move entirely to `ADMIN_EMAILS` env var.
12. **ATR is SMA, not Wilder.** `lib/backtest/scannerBacktest.ts` (L71–L80). Use the correct Wilder smoother already implemented in `lib/backtest/indicators.ts` (L127–L150). Stops/sizing currently understate volatility in trends.
13. **No commission / spread / borrow modeled in backtest.** `lib/backtest/assumptions.ts` (L30–L35) — only slippage. Add per-asset-class commission (equity 1bp, crypto 20bp, FX 2 pips) on both legs.
14. **Stochastic div-by-zero produces millions.** `lib/backtest/scannerBacktest.ts` (L124) — `(hMax - lMin || 1e-9)` makes K explode to ~10⁷. Treat zero range as `NaN` (or 50 if you must) — never compute.
15. **Options Greeks not requested.** `app/api/deep-analysis/route.ts` (L326–L335) — Alpha Vantage `REALTIME_OPTIONS_FMV` called without `require_greeks=true`; falling back to BS estimate.
16. **Missing options data does not reduce confidence.** `app/api/options-confluence/gex/route.ts` returns `coverage:'none'` but composite score isn't penalised. Doctrine (`options-data-rules.md`) requires Evidence Quality reduction, not proxy.
17. **Tier-gating after AI call.** `app/api/portfolio/analyze/route.ts` (L40–L70) calls OpenAI before checking tier; free users can burn quota. Move 403 check before the OpenAI request.
18. **IP rate-limit trusts `x-forwarded-for` blindly.** `middleware.ts` (L80–L81), `lib/rateLimit.ts` (L162–L167). Document trusted proxy or take only first IP after validating CIDR.
19. **Scanner form has no labels / aria-disabled.** `app/tools/scanner/page.tsx` — screen-reader users cannot operate the scanner. Add `<label htmlFor>`, `aria-disabled`.
