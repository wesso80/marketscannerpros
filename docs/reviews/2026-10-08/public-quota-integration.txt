Implemented
• PUBLIC_DAILY_QUOTAS_ENABLED opt-in, default off. No environment changes made.
• New server-only access resolver reads subscription state directly, fails closed on database errors, ignores stale paid cookie grants, preserves signed admin/operator bypass.
• Signed-in /api/golden-egg reserves by canonical instrument before computation; Free can access three successful core reports when opted in. Reopening and cached reports use the same unlock. Crypto aliases use existing stable CoinGecko identities; unmapped identities are withheld. Forex remains outside this new path.
• Successful public projection completes a report; provider failure releases it. Demo/absent canonical evidence releases rather than spends a report. If completion storage fails after output exists, capacity remains reserved and the response is unavailable instead of granting an uncounted report.
• New /api/public-usage returns only counts and reset metadata, private/no-store; no subject, instrument, question, response or token fields. Symbol page displays remaining/pending usage and local reset time, reloading when report state changes and at reset. Counter is hidden while rollout is off.
• Migration 127 adds private replay JSON. AI completion now requires a stored response (maximum 256 KiB) in the same update as completion. Matching completed retries return it internally. Private replay is never included in quota-status output.
