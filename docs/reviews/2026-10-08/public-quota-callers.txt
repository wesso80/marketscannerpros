Implemented
1. Shared wrapper for /api/ai/copilot, /api/msp-analyst, /api/ai/explain POST and /api/ai/analyst-context POST. Authenticated, server-verified Free/Pro plan; one daily AI ledger across callers. Legacy checks are skipped only inside a successfully admitted public request context. Admin/operator bypass and disabled rollout preserve legacy handlers. Existing usage analytics writes remain.
2. Stable request fingerprints cover sorted full request JSON and feature name. Copilot submits an Idempotency-Key using its user message ID; other clients without IDs replay identical request context within the quota day. A supplied ID with changed context conflicts. Pending/over-limit requests do not execute handlers. Successful JSON responses are stored before returning; retried requests replay that result. All new wrapper responses are private/no-store.
3. Provider-attempt markers distinguish errors before model execution from unknown outcomes after a model request. Invalid/pre-provider failures release a reservation. Interrupted/5xx provider outcomes remain pending for reconciliation. Quota storage failure never grants access. Requests are limited to 64 KiB, replay results to 256 KiB.
4. New metric explanations use a cache key scoped to account plus full request fingerprint, preventing the prior shared value-bucket cache from crossing public user/context boundaries. Public GET cache lookup is disabled under rollout; scoped POST supplies replay. Admin GET remains available. Existing shared cache records are not altered or treated as safe public per-user answers.
5. /api/deep-analysis and /api/symbol-comparison check a completed same-day canonical Symbol unlock before fetching evidence/history for non-admin public users. They do not consume another report. Chart route and its two helper files were copied from our PR #493 to make this branch build independently; coordinate that overlap when assembling the release. Chart UI changes still live in #493.
6. Automatic Symbol prose is separate from submitted question allowances (the stated recommended assumption). Migration 128 adds a private summary-attempt table. At most one attempt per account/browser + canonical instrument + Eastern day. Simultaneous requests cannot duplicate it. A fingerprint binds prose to the exact evidence prompt: changed evidence produces current deterministic sections without old AI prose or another automatic model call. Failed/pending attempts do not retry that day. No automatic summary consumes an AI-question credit.
7. Signed-out report access uses a 30-day HttpOnly, SameSite=Lax HMAC-signed browser cookie, Secure over HTTPS. Explicit same-origin POST /api/public-usage creates/reuses the identity behind the existing per-IP limiter. Symbol page's Try one report action initializes the cookie and refetches the report. A visitor gets one distinct canonical instrument/day and no submitted AI questions. Status and section access resolve that same identity. Engine telemetry is not given a fake authenticated workspace.
8. Usage refreshes after Copilot responses and actual report state changes. The guest, Free, Pro and exhausted counters show local-time reset metadata without exposing ledger identifiers or replay content.
