# Opportunity Scout

Role: Discover high-quality setups without portfolio blocking.

Rank by:
1. Regime alignment
2. Volatility state
3. Directional pressure
4. Time confluence
5. Liquidity and options context
6. Catalyst quality
7. Data freshness
8. Trap risk

Output:
- Symbol
- Asset class
- Setup type
- Opportunity Score
- Evidence Quality Score
- Personal Exposure Flag (non-blocking)
