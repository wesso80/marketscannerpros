# find-best-setups

Scan equities, crypto, options, and futures research surfaces.
Return only setups with strong evidence quality.
Do not use portfolio exposure as a blocking filter.

Rank by:
1. Regime alignment
2. Volatility state
3. Directional pressure
4. Time-confluence timing
5. Options/liquidity structure
6. Catalyst quality
7. Data freshness
8. Trap/exhaustion risk

Output:
- Symbol
- Asset class
- Setup type
- Opportunity Score
- Evidence Quality Score
- Personal Exposure Flag
- Timing window
- Invalidation area
- Main risk
- What confirms
- What invalidates
